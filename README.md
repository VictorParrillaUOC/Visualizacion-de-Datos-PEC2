# Visualizacion-de-Datos-PEC2

En esta práctica hemos realizado 3 visualizaciones:

1) Area Chart: Gráfica popular para visualizar tendencias a lo largo del tiempo. Fuente de datos: https://www.statista.com/statistics/216618/nintendo-digital-game-sales/
2) Linear Dendogram: Visualización específica muy habitual en problemas de clustering. Fuente de datos: https://www.kaggle.com/datasets/mohammadtalib786/countries
3) Violin Plot: Gráfica para visualizar distribución de datos entre diferentes grupos. Fuente de datos: https://github.com/gianantonel/Students_Performance/blob/main/StudentsPerformance.csv

En este repositorio se encontrarán las visualizaciones, mientras que en los videos entregados en el campus se encontrarán las explicaciones.

Para encontrar los datos he utilizado las páginas statista, kaggle y github, mientras que para entender las visualizaciones, los tipos de datos con los que se suele trabajar y los problemas que resuelven he utilizado datavizcatalogue.com y data-to-viz.com.
